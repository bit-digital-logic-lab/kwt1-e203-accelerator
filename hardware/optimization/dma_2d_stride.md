# 二维行步长 DMA 原型（2026-10-17）

`kwt_dma_2d` 在现有连续字 DMA 外增加行数、每行字数、外存字节行距和
本地 SRAM 字行距。它按行调用原 DMA，支持从行主序 B[64,256]
抽取 B[64,16] 列块，也支持将输出 tile 的 32-bit 结果按完整矩阵
行距写回。首地址及每行外存行距必须按 128-bit 总线拍对齐。

设计在搬运前顺序检查每行的外存和 SRAM 范围。这个预检增加 `rows`
拍启动延迟，但避免用可变行数乘步长的宽组合乘法器，也避免末行越界时
前几行已经写入。描述符在启动时锁存，运行中改变输入不会修改任务。

小仿真：

```bash
bash hardware/rtl/dma/tb/run_2d_verilator.sh
bash hardware/synth/run_dma_2d.sh
```

Verilator 测试包含：64×16 B 块恰好装入 1,024 字 B bank；有反压的
三行、每行 6 字输出写回；尾拍字节选通不破坏邻近数据；行距对齐、
外存和本地越界、空任务报错；启动后修改输入描述符不影响任务。
Yosys 粗综合 `check -assert` 通过，优化后无 `$mul/$div/$mod`。

这还是**独立模块**，没有接入 tile FSM 或真实 System Bus。当前的
512 KB 外存和 128-bit 总线是开发模型；正式平台接口、SRAM 宏端口、
bank 同拍冲突与吞吐尚需验证。预检等待也要计入后续整层任务周期。
