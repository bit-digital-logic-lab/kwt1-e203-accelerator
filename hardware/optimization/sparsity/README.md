# KWT-1 本科 FFN1 稀疏实测

本实验只分析 RCL/RTL 必做的 `X[99,64] @ W[64,256] + bias`。`98×40` MFCC、模型前段和每层 `X` 的提取在电脑端完成。读取已冻结的 A12W10 对称量化权重/尺度；不剪枝、不舍入权重、不修改任何参数。近零统计仅是反事实比例，不能作为精度合格的证据。

## 复现

从工程根目录执行：

```bash
python3 hardware/optimization/sparsity/profile.py
```

输入为 `software/.build/quant_samples_12labels_40.npz`、`software/results/ffn1_a12w10_static_sym_12labels_40.npz` 和 `software/weights/kwt1_fp32.npz`；脚本在 `profile.json` 记录 SHA-256。CPU 上重跑 480 条 validation 样本，经冻结 FP32 模型抽取全部 12 层 FFN1 输入，再按冻结逐层尺度 `rint`、截到 `[-2047,2047]` 转 INT12 容器。抽样独立检查此转换，零乘积计数另用广播布尔张量对一层一条样本校对。2 样本 smoke 和 480 样本正式运行均退出码 0。统计使用验证集只观察固定配置，不用它调量化参数。

## 结果

| 项目 | 实测 |
| --- | ---: |
| 权重精确零 | 0.23346% |
| 激活精确零 | 0.10740% |
| 乘积精确零，含两者交集去重 | 0.34062%，31,823,902 / 9,342,812,160 MAC |
| 权重/激活绝对整数值 ≤1 | 0.68970% / 0.32016% |
| 若把绝对值 ≤1 当零，零乘积反事实上界 | 1.00769% |
| 若把绝对值 ≤2 当零，零乘积反事实上界 | 1.66747% |
| 整条激活行 / 整个权重输出列为零 | 0 / 570,240；0 / 3,072 |
| 16×16 tile 中整 K 步可跳过 | 0 / 41,287,680 |
| 16×16 tile 中 4/8/16 连续 K 块可跳过 | 均为 0 |

在现有密集 16×16 广播/累加阵列上，精确零可用于**按 PE 门控以尝试降低动态功耗**，但没有整 tile 的 K 步可跳，故此数据上的整拍计算周期改善上界为 **0**。即使另做逐 MAC 不规则调度，理想可省乘法次数也只有 0.34062%，且检测、索引和压缩开销未计；不能把它当作 0.34% 实际加速。对绝对值 ≤1/2 做舍入会改变数值，需另做训练划分确定阈值、逐层 NRMSE、RTL 逐位对照；本实验没有执行该方案。

这只是 480 条本地验证样本及当前 A12W10 参数包的统计。没有修改 RTL、没有做 Verilator 周期对照、综合面积或功耗测量；不能外推到官方隐藏样本、SoC 总周期或芯片能耗。偏置、装载、写回始终存在。
