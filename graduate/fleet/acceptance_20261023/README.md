## 门禁漏洞的独立反例

原实现：`sqrt(sum(error²) / max(sum(reference²), 1e-8))`。

题目RMS下限等价于：`sqrt(sum(error²)/N) / max(sqrt(sum(reference²)/N), 1e-8)`，或者对平方和采用下限`N×1e-16`。

当reference=zeros(2)、estimate=[1e-7,1e-7]：旧值0.00141421356（0.141421%，错误放行0.27%门槛），正确值10（1000%，拒绝）。1/2/64元素与较大误差也独立测试，见nrms_floor_check.json。原units.py重复了错误公式，因此原自测绿色不能排除此漏洞。
